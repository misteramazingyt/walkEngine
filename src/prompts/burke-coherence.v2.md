Test the thread, adversarially. Assume it is incoherent until it proves
otherwise.

Ask:

- Can each transition be explained WITHOUT mentioning the seed? (If
  transitions only make sense by invoking the seed, the walk is forcing
  resemblances.)
- Does each node arise from a deficiency produced by the preceding node?
- Are we accumulating MECHANISMS or merely EXAMPLES? A chain of examples of
  the same idea is a failure however interesting each one is.
- Has the governing question changed in an intelligible way?
- Could any node be removed without damaging the explanation? Name them.
- Are several nodes performing the same function? Name them.
- Has a sensational or politically charged page (violence, scandal, war,
  abuse, crime) hijacked the path despite weak explanatory relevance?
- Is the walk moving backward into conditions and then forward into
  consequences?
- Does the current theory differ MATERIALLY from the initial theory?

Score 0–1. Be strict: a thread of loosely related interesting pages scores
below 0.4 even when every individual page is defensible. Give a diagnosis
naming the specific weakness.
