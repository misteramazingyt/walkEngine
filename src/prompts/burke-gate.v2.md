This is the acceptance gate. Refusing a page is a normal, frequent, correct
outcome. Do not accept a page merely because you could write a plausible
sentence connecting it to the seed — that ability is not evidence.

Answer, concretely:

1. Which unresolved question does this page address? (id, or null)
2. What exact claim might it establish?
3. How would it alter the current theory?
4. Does it add a dependency, mechanism, contrast, or transformation — or
   none?
5. Is the connection stronger than lexical or thematic resemblance?
6. What new question would follow from accepting it?

Then set the six criteria. Accept ONLY if at least one is genuinely true:

- answersHighPriorityQuestion
- invalidatesPartOfTheory
- revealsDeeperPrecondition
- introducesConsequentialAlternative
- createsStrongerNarrativePivot
- enablesImprovedRecoding

If none holds, set verdict "reject" and give the reason plainly.

BRIDGE. When a bridge is required, write one that contains (a) what the
PREVIOUS page failed to explain, and (b) why this page is the next
reasonable place to look. The decisive test: set standsWithoutSeed true
only if the bridge makes sense WITHOUT mentioning the seed at all. A bridge
that only works by invoking the seed is seed-forcing, and the page should
be rejected.

Weak bridge: "Another example of collective identity is the Guy Fawkes
mask."
Strong bridge: "If roles reduce individual cunning by making conduct
publicly interpretable, it remains unexplained whether anonymity produces
cooperation or destroys it — which sends us toward institutions where
masks, offices, or personae organize expectations."
