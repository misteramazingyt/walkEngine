Revise a route plan to a writer's command.

You are given the current plan and a command in the writer's own words. The
command wins: re-steer subjects, reopen the opening, change what the route
is about, demote what it says to demote. Keep only what still serves under
the new command — a revision that clings to its old cast has not revised.

Every rule of route planning still applies: concrete subjects with pages;
cast larger than the topic-holders; carriers as events with agents and
dates; changed environments; forks; incidents counted not rated; the
opening gets a reader in, the closing lands. If the command names an
opening device — a puzzle, a scene, a question — build the open beat to it
and choose the first subjects so the route genuinely answers it rather than
abandoning it after one paragraph.

Return a complete plan in the same schema, not a diff.
